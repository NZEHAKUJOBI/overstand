{% translate "5. Investor Inquiries" %}

{% blocktranslate trimmed %}When an investor submits a contact form, it appears as an inquiry in your dashboard. Responding promptly is critical — investors who don't hear back quickly move on. Navigate to Sidebar → Inquiries.{% endblocktranslate %}

{% translate "Status" %}{% translate "Meaning" %}{% translate "What to do" %}
{% translate "New" %}{% translate "Just received, not yet viewed" %}{% translate "Open and read it. Respond within 24–48 hours." %}
{% translate "In Progress" %}{% translate "Being handled by your team" %}{% translate "Continue follow-up. Update status as it progresses." %}
{% translate "Qualified" %}{% translate "Investor confirmed as serious" %}{% translate "Escalate to senior staff. Arrange meetings." %}
{% translate "Closed" %}{% translate "Concluded" %}{% translate "Archive. No further action needed." %}

{% translate "Opening and Responding to an Inquiry" %}

1
{% translate "Click any inquiry in the list" %}

{% translate "Opens the full inquiry showing the investor's name, company, message, and contact details." %}

2
{% translate "Read the inquiry carefully" %}

{% translate "Note the sector they're interested in, what they're asking, and their level of seriousness." %}

3
{% translate 'Update the status to "In Progress"' %}

{% translate "This prevents duplicate responses from your team." %}

4
{% translate "Respond to the investor directly from your work email" %}

{% translate "The platform does not send replies on your behalf — you contact them yourself." %}

5
{% translate "Update the status as the conversation progresses" %}

{% blocktranslate trimmed %}Move to "Qualified" once confirmed serious. Close when concluded.{% endblocktranslate %}

{% translate "Response time is critical" %}

{% blocktranslate trimmed %}International investors evaluate countries partly by how quickly they respond. Aim to respond to every New inquiry within 48 hours. Delays signal disorganisation and cost your country investment opportunities.{% endblocktranslate %}
