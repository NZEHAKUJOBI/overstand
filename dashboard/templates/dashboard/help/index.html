{% blocktranslate trimmed %} The IPAWAS Digital Platform is the central hub for all Investment Promotion Agencies (IPAs) across West Africa. It allows each member state to manage and publish their investment profile, opportunities, and respond to investor inquiries — all in one place. {% endblocktranslate %}

{% translate "Who Uses This Platform?" %}

{% blocktranslate trimmed %}There are two types of users on the IPAWAS platform. Your account type determines which dashboard you see and what you can do.{% endblocktranslate %}

{% translate "HQ Admin" %} {% translate "IPAWAS Headquarters" %}

{% blocktranslate trimmed %}Full system access. Manages all member states, all users, platform-wide reports, analytics, and system settings. Typically 1–3 people at the IPAWAS Secretariat.{% endblocktranslate %}

{% translate "IPA Staff" %} {% translate "Country / Member State" %}

{% blocktranslate trimmed %}Access limited to their own country's dashboard. Manages opportunities, investor inquiries, country profile, and their team. Each IPA has its own staff.{% endblocktranslate %}

{% translate "Not sure which type you are?" %}

{% blocktranslate trimmed %}When you log in, the platform automatically sends you to your correct dashboard. HQ Admins go to /dashboard/hq/ and IPA Staff go to /dashboard/your-country/.{% endblocktranslate %}
