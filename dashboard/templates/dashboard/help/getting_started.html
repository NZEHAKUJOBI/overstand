{% translate "Getting Started" %}

{% blocktranslate trimmed %} This section walks you through your very first experience with the IPAWAS platform — from receiving your invitation email to exploring your dashboard. Even if you have never used a web-based management tool before, this guide will get you up and running confidently. {% endblocktranslate %}

{% translate "Step 1 — Accepting Your Invitation" %}

{% blocktranslate trimmed %}You do not create your own account on IPAWAS. An administrator will send you a personalised invitation email. Here's what to expect:{% endblocktranslate %}

1
{% translate "Check your email inbox" %}

{% blocktranslate trimmed %}Look for an email from the IPAWAS platform with the subject line "You've been invited to join IPAWAS". Check your Spam/Junk folder if you don't see it within a few minutes.{% endblocktranslate %}

2
{% translate "Click the invitation link" %}

{% blocktranslate trimmed %}Inside the email, there is a blue "Accept Invitation" button. Click it. This link is unique to you and expires after 7 days — do not share it with anyone.{% endblocktranslate %}

3
{% translate "Create your password" %}

{% translate "You will be taken to a registration page. Enter your first name, last name, and choose a secure password. Your email address is already filled in automatically." %}

4
{% translate 'Click "Create My Account"' %}

{% translate "You will be automatically logged in and taken directly to your dashboard — no need to log in separately." %}

{% translate "Invitation link expired?" %}

{% translate "If the link has expired (older than 7 days), contact the person who invited you and ask them to resend the invitation. Do not try to register without an invitation link." %}

{% translate "Password tips" %}

{% blocktranslate trimmed %}Use at least 8 characters, mixing upper and lower case letters, numbers, and a symbol (e.g. IpaWest@2026). Avoid using your name or "password123".{% endblocktranslate %}

{% translate "Step 2 — Logging In" %}

{% translate "After your first login, you will need to log in each time you return to the platform." %}

1
{% translate "Go to the IPAWAS platform" %}

{% blocktranslate trimmed %}Open your web browser (Chrome, Firefox, or Edge recommended) and navigate to the IPAWAS website. Click "Login" in the top navigation bar.{% endblocktranslate %}

2
{% translate "Enter your email and password" %}

{% translate "Type the email address that was invited and the password you set during registration." %}

3
{% translate 'Click "Sign In"' %}

{% translate "The system will check your credentials and automatically send you to the correct dashboard based on your role." %}

{% translate "Forgot your password?" %}

1
{% translate 'On the login page, click "Forgot password?"' %}

{% translate "Located below the Sign In button." %}

2
{% translate 'Enter your email address and click "Send Reset Link"' %}

{% translate "An email with a reset link will arrive within a few minutes." %}

3
{% translate "Click the link in the email and set a new password" %}

{% translate "Reset links expire after 24 hours." %}

{% translate "Step 4 — Setting Up Your Profile" %}

{% translate "Before you start using the platform, take a moment to complete your personal profile." %}

1
{% translate 'Find "My Settings" in the sidebar' %}

{% blocktranslate trimmed %}Scroll to the bottom of the left sidebar navigation. You will see a My Settings link.{% endblocktranslate %}

2
{% translate "Update your personal details" %}

{% translate "Here you can update your first name, last name, and contact details." %}

3
{% translate "Change your password" %}

{% blocktranslate trimmed %}Navigate to Settings → Password and set a new, strong password that only you know.{% endblocktranslate %}

{% translate "Change your password on first login" %}

{% translate "Although the invitation process already has you set a password, it is good practice to change it again after your first session to ensure it is private." %}

{% translate "Step 5 — Logging Out Safely" %}

{% translate "Always log out when you are done, especially if you are using a shared or public computer." %}

1
{% translate 'Find "Logout" in the sidebar' %}

{% blocktranslate trimmed %}Scroll to the bottom of the left sidebar. You will see a Logout link.{% endblocktranslate %}

2
{% translate 'Click "Logout"' %}

{% translate "You will be immediately signed out and redirected to the home page. Your session is ended securely." %}

{% translate "Never close the browser tab without logging out" %}

{% translate "Simply closing the tab may leave your session active, allowing someone else using the same computer to access your account. Always click Logout first." %}
